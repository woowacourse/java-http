## 기능 요구 사항

- [x] 인덱스 페이지에 접근할 수 있다.
- [x] CSS 파일 호출이 가능하다.
- [x] 쿼리 파라미터의 로그인 정보가 일치하면 콘솔 창에 로그로 회원을 조회한 결과가 나온다.
- [x] 로그인 성공 시 302를 반환하고, /index.html로 리다이렉트 된다.
- [x] 로그인 실패 시 302를 반환하고, 401.html로 리다이렉트 된다.
- [x] 회원가입 페이지에 접근할 수 있다.
- [x] 회원가입을 완료하면 /index.html로 리다이렉트 된다.
- [x] 요청 헤더에 JSESSIONID가 없으면 응답 헤더에 Set-Cookie를 반환한다.
- [x] 로그인 한 상태에서 /login에 접근하면, /index.html로 리다이렉트 된다.
- [ ] HttpRequest 요청을 처리하는 클래스를 추가한다.
