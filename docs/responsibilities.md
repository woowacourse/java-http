# 객체와 책임

## User

### 책임

회원의 인증 정보를 판단한다.

### 계약

- [x] 입력된 비밀번호가 저장된 비밀번호와 같으면 일치한다고 판단한다.
- [x] 입력된 비밀번호가 저장된 비밀번호와 다르면 일치하지 않는다고 판단한다.

## InMemoryUserRepository

### 책임

메모리에 회원을 저장하고 조회한다.

### 계약

- [x] 회원을 저장하면 계정으로 조회할 수 있다.
- [x] 등록되지 않은 계정을 조회하면 빈 결과를 반환한다.

## Session

### 책임

한 세션에 속한 상태를 보관한다.

### 계약

- [x] 이름으로 값을 저장하면 같은 이름으로 조회할 수 있다.
- [x] 저장된 값을 제거하면 이후 조회되지 않는다.

## Manager

### 책임

서버에서 사용하는 세션의 저장과 조회를 추상화한다.

### 계약

- [x] 세션을 등록할 수 있다.
- [x] ID로 세션을 조회할 수 있다.
- [x] ID로 세션을 제거할 수 있다.

## SessionManager

### 책임

여러 요청에서 사용하는 세션을 관리한다.

### 계약

- [x] 세션을 등록하면 ID로 조회할 수 있다.
- [x] 존재하지 않는 ID를 조회하면 빈 결과를 반환한다.
- [x] 세션을 제거하면 이후 해당 ID로 조회할 수 없다.

## HttpCookie

### 책임

Cookie 헤더를 해석해 쿠키 값을 제공한다.

### 계약

- [x] Cookie 헤더에 존재하는 쿠키를 이름으로 조회할 수 있다.
- [x] 존재하지 않는 쿠키를 조회하면 빈 결과를 반환한다.

## RequestTarget

### 책임

HTTP 요청 대상을 경로와 Query Parameter로 해석한다.

### 계약

- [x] 요청 대상에서 경로를 구분한다.
- [x] 요청 대상에 Query Parameter가 있으면 이름으로 조회할 수 있다.
- [x] 요청 경로가 주어진 경로와 같은지 판단한다.
- [x] 요청 경로의 확장자를 제공한다.

## HttpRequest

### 책임

HTTP 요청 메시지를 읽고 요청 정보를 제공한다.

### 계약

- [x] 요청 메서드와 요청 대상을 읽는다.
- [x] 헤더를 이름으로 조회할 수 있다.
- [x] Cookie 헤더에서 쿠키 값을 조회할 수 있다.
- [x] Content-Length의 바이트 수만큼 본문을 읽는다.
- [x] Form 본문의 값을 UTF-8로 해석한다.
- [x] 본문이 Content-Length보다 짧으면 요청을 정상적으로 해석하지 않는다.

## HttpResponse

### 책임

HTTP 응답을 작성하고 HTTP/1.1 응답 메시지로 직렬화한다.

### 계약

- [x] 상태, 헤더, 본문을 작성할 수 있다.
- [x] 본문을 작성하면 본문 길이에 맞는 `Content-Length`를 포함한다.
- [x] 작성된 상태, 헤더, 본문을 HTTP/1.1 응답 메시지로 직렬화한다.
- [x] 리다이렉트를 설정하면 `302` 상태와 `Location` 헤더를 포함한다.
 
## Http11Processor

### 책임

하나의 연결에서 HTTP 요청 처리를 조정하고 응답을 전송한다.

### 계약

- [x] 연결에서 HTTP 요청을 읽어 처리한다.
- [x] 처리 결과인 HTTP 응답을 연결에 쓴다.
- [x] 서버가 관리하는 세션 저장소를 사용한다.
- [x] 처리 중 발생한 예외를 로그로 남긴다.

## Connector

### 책임

클라이언트 연결을 받아 HTTP 처리를 시작한다.

### 계약

- [x] 클라이언트 연결을 받아 Processor에 전달한다.
- [x] 각 요청 Processor에 동일한 서버 세션 저장소를 제공한다.

## Tomcat

### 책임

웹 서버 구성 요소의 생명주기를 시작하고 종료한다.

### 계약

- [x] 서버에서 공유할 SessionManager를 생성한다.
- [x] Connector를 시작한다.
- [x] 서버 종료 시 Connector를 종료한다.

## RequestLine

### 책임

HTTP 요청의 첫 줄을 해석해 요청 정보를 제공한다.

### 계약

- [x] `METHOD request-target HTTP-version` 형식을 해석한다.
- [x] 요청 메서드를 제공한다.
- [x] 요청 대상을 제공한다.
- [x] HTTP 버전을 제공한다.
- [x] 올바르지 않은 Request Line은 허용하지 않는다.

## StatusLine

### 책임

HTTP 응답의 첫 줄을 구성한다.

### 계약

- [x] HTTP 버전과 상태를 이용해 Status Line을 만든다.
 
## HttpStatus

### 책임

HTTP 응답 상태를 표현한다.

### 계약

- [x] 상태 코드와 Reason Phrase를 제공한다.

## Controller

### 책임

HTTP 요청을 처리해 HTTP 응답을 작성한다.

### 계약

- [x] 요청을 처리한 결과를 전달받은 `HttpResponse`에 작성한다.

## AbstractController

### 책임

HTTP Method에 따라 Controller의 처리 흐름을 분기한다.

### 계약

- [x] GET 요청은 GET 처리에 위임한다.
- [x] POST 요청은 POST 처리에 위임한다.
