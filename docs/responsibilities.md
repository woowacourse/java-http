# 객체와 책임

## User

- [x] 입력된 비밀번호가 비밀번호와 일치하는지 판단한다.

## InMemoryUserRepository

- [x] 등록된 회원을 가진다.
- [x] 기본 회원을 가진다.
- [x] 회원을 저장한다.
- [x] 계정으로 등록된 회원을 찾는다.
- [x] 등록되지 않은 계정은 빈 결과로 반환한다.

## SessionManager

- [x] 여러 요청에서 사용할 세션을 ID로 저장한다.
- [x] ID로 저장된 세션을 찾는다.
- [ ] ID로 저장된 세션을 제거한다.

## Session

- [x] 이름별 객체 값을 저장하고 조회한다.
- [x] 이름으로 저장된 값을 제거한다.
- [ ] 세션을 무효화한다.

## HttpCookie

- [x] 요청의 `Cookie` 헤더를 이름과 값으로 해석한다.
- [x] 이름으로 쿠키 값을 찾는다.

## RequestTarget

- [x] 유효한 요청 대상을 요청 경로와 Query Parameter로 해석한다.
- [x] 요청 경로가 주어진 경로와 일치하는지 판단한다.
- [x] Query Parameter가 존재하는지 판단한다.
- [x] 이름으로 Query Parameter를 찾는다.
- [x] 요청 경로의 확장자를 반환한다.

## HttpRequest

- [x] 입력 스트림에서 요청 메서드, 대상, 헤더, 본문을 읽는다.
- [x] `Content-Length`에 맞춰 본문을 바이트 단위로 읽는다.
- [x] 요청 메서드와 경로가 주어진 값과 일치하는지 판단한다.
- [x] 요청 경로와 확장자를 반환한다.
- [x] 이름으로 요청 헤더를 찾는다.
- [x] 이름으로 요청 쿠키 값을 찾는다.
- [x] 폼 본문에서 이름으로 입력값을 찾아 UTF-8로 해석한다.

## HttpResponse

- [x] 응답 본문 길이에 맞는 `Content-Length` 헤더를 가진다.
- [x] 상태 코드와 헤더, 본문으로 HTTP/1.1 응답 메시지를 만든다.
- [x] 지정한 경로를 `Location` 헤더로 보내는 `302` 응답을 만든다.
- [x] 응답 헤더가 있는지 확인한다.

## Http11Processor

- [x] 소켓에서 HTTP 요청을 읽고 응답한다.
- [x] 요청 처리 결과에 맞는 HTTP 응답을 결정한다.
- [x] HTTP 응답을 출력 스트림에 쓴다.
- [x] 루트 페이지 요청에 `Hello world!`로 응답한다.
- [x] 요청 경로에 해당하는 정적 리소스를 반환한다.
- [x] 리소스 확장자에 맞는 `Content-Type`으로 응답한다.
- [x] 로그인 페이지 요청에 로그인 페이지를 반환한다.
- [x] 로그인 요청의 폼 본문에서 계정과 비밀번호를 찾는다.
- [x] 계정으로 등록된 회원을 찾는다.
- [x] 회원과 비밀번호로 로그인 성공 여부를 판단한다.
- [x] 로그인에 성공하면 `/index.html`로 리다이렉트한다.
- [x] 로그인에 실패하면 `/401.html`로 리다이렉트한다.
- [x] 회원가입 요청의 계정 정보로 회원을 저장한다.
- [x] 요청 쿠키에 대응하는 세션이 없으면 UUID 세션을 등록하고 ID를 쿠키로 보낸다.
- [x] 로그인에 성공하면 요청에 대응하는 세션에 `User`를 저장하고 같은 ID를 쿠키로 보낸다.
- [x] `GET /login`에서 세션에 `User`가 있으면 `/index.html`로 리다이렉트한다.
- [x] 조회한 회원의 비밀번호를 제외한 정보를 로그로 남긴다.
- [ ] 연결된 호스트와 포트를 로그로 남긴다.
- [ ] 처리 중 발생한 예외를 로그로 남긴다.
