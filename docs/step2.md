# 2단계 로그인 구현하기

## 인수 조건

### 로그인

- [x] `POST /login`의 계정 정보가 일치하면 `/index.html`로 리다이렉트한다.
- [x] 계정이 없거나 비밀번호가 일치하지 않으면 `/401.html`로 리다이렉트한다.
- [x] `GET /login`의 Query String으로는 로그인하지 않는다.

### 회원가입

- [x] 회원가입 페이지는 POST 방식으로 회원가입을 요청한다.
- [x] `POST /register`로 회원을 저장하면 이후 해당 계정으로 로그인할 수 있다.
- [x] 회원가입이 완료되면 `/index.html`로 리다이렉트한다.

### JSESSIONID

- [x] 유효한 JSESSIONID가 없으면 새 세션을 생성하고 ID를 쿠키로 응답한다.
- [x] 유효한 JSESSIONID가 있으면 기존 세션을 사용한다.
- [x] 서버에 존재하지 않는 JSESSIONID가 오면 새 세션을 생성한다.

### 로그인 세션

- [x] 로그인에 성공하면 응답의 JSESSIONID가 가리키는 세션에 User가 저장된다.
- [x] 로그인한 세션으로 `GET /login`에 접근하면 `/index.html`로 리다이렉트한다.
- [x] 로그인하지 않은 세션으로 `GET /login`에 접근하면 로그인 페이지를 응답한다.
